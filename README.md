# EmjudeCodingTech

A full-stack **Flask web application** that powers my software-development
business: a public marketing/portfolio site, a blog, and a contact pipeline —
all managed through a custom, login-protected **admin CMS** that I built from
scratch (no CMS framework, no page builder).

> This is a real, deployed application I wrote to run my own business, not a
> tutorial or a static template. Everything below is server-rendered Flask
> backed by a relational database.

---

## What it does

**Public site**
- Home, About, Services, and Portfolio pages rendered server-side from the database
- **Blog** with pagination, category filtering, and title/excerpt search
- **Contact form** that persists enquiries and emails me a formatted notification

**Admin CMS** (`/admin`, authentication required)
- Dashboard with live counts (posts, projects, unread messages)
- Full CRUD for blog **posts** and portfolio **projects**
- Inbox for reading, marking-read, and deleting contact **messages**

---

## Backend features worth a look

These are the parts I'd most enjoy talking through:

| Area | What I built |
|------|--------------|
| **Auth** | Session login with `flask-login`; passwords hashed with Werkzeug's `generate_password_hash` / `check_password_hash`; all admin routes gated by `@login_required` |
| **Data model** | Four SQLAlchemy models (`Admin`, `Post`, `Project`, `Message`) with computed properties — e.g. `read_time`, `tag_list`, `stack_list`, unique-slug generation |
| **Blog engine** | Server-side pagination, category filters, `ILIKE` search, automatic slugification with collision handling, and related-post lookups |
| **Email system** | On contact submit, the app saves to the DB *and* sends two emails: a rich HTML notification to me and an HTML auto-reply to the sender. The HTML is generated by hand-written, email-client-safe template functions with **XSS-safe escaping** (`markupsafe.escape`) on every user field |
| **Custom CLI** | Flask CLI commands for operating the app: `init-db`, `create-admin`, `seed-projects`, and an idempotent `migrate-projects` that ALTERs the table only for missing columns |
| **Config** | 12-factor style — all secrets and environment-specific settings read from environment variables via `python-dotenv`, with safe defaults |

### Where to start reading
- **`app.py`** — routes, the contact/email flow, and the CLI commands
- **`models.py`** — the data model and computed properties
- **`config.py`** — environment-driven configuration

## Tech stack

- **Python 3 / Flask** — application framework and server-side rendering (Jinja2)
- **Flask-SQLAlchemy** — ORM over a SQLite database
- **Flask-Login** — session-based admin authentication
- **Flask-Mail** — transactional email (owner notification + auto-reply)
- **Vanilla JS + CSS** — front-end interactivity and styling (no heavy framework)

## Running it locally

```bash
# 1. Clone and enter the project
git clone https://github.com/kingkong-nyame/emjudecodingtech.git
cd emjudecodingtech

# 2. Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Configure environment variables
cp .env.example .env            # then edit .env with your values

# 4. Initialise the database and seed content
export FLASK_APP=app.py         # Windows (PowerShell): $env:FLASK_APP="app.py"
flask init-db
flask seed-projects
flask create-admin              # prompts for an admin username + password

# 5. Run
flask run                       # http://127.0.0.1:5000
```

The public site is at `/`; the admin panel is at `/admin/login`.

For deploying to a live server, see [`DEPLOY.md`](DEPLOY.md).
